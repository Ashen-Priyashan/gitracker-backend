# GitTracker Backend

Backend service for GitTracker — GitHub Profile Analytics System.

## Tech Stack
- Spring Boot
- PostgreSQL
- Redis
- GitHub REST API

## Features (Planned)
- GitHub user data fetching
- Repository analytics
- Language breakdown
- Caching with Redis
- Score engine

## Architecture
Frontend → Backend → GitHub API → Cache/DB
